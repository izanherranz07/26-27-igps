## 4. Primer commit

Dentro de `AEC-GIT` creé un archivo de texto vacío, `README.txt`. Después lo añadí al área de staging, creé un commit y subí los cambios a mi fork:

```bash
git add .
git commit -m "docs: nuevo archivo"
git push origin main
```
